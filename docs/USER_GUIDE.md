# CareApp User Guide

**Project:** CareApp  
**Source Code Repository:** https://github.com/mrdahir/CareAi/

---

## Features

### Health Chat

Ask questions about contraception, family planning, and reproductive health. Responses stream in real time when the API is available.

### Recommendations

Complete the short survey (age, breastfeeding, goals, duration) to get ranked contraceptive options.

### Myth Buster

Enter a statement you have heard; CareApp checks it against verified facts.

### Language

Use the header dropdown for **English, Swahili, Amharic, French, or Somali**. English has the fullest content; additional languages are supported in the interface.

---

## Important

CareApp is **not a doctor**. For emergencies or personal medical decisions, visit a qualified health provider.

---

## Privacy

Chat may be stored on the server when the non-streaming chat path is used. Do not share passwords or national IDs in chat.
